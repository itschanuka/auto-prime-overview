# Source Code Access

The source code for Auto Prime DMS is **private** to protect the business logic, database architecture, and system design that took 6 months to build.

---

## Why Private?

This system represents significant original work — 18 database tables, 8 migrations, a full REST API, 13 frontend modules, and production-grade security architecture. Making it fully public would hand that work to anyone freely.

The overview in this repo — README, architecture doc, database schema, API reference — is provided so you can evaluate the depth and quality of the work without needing the source.
